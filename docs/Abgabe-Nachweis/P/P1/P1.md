## Offizielle Anforderung

> Das System enthält mindestens einen AI Agent, der echte Tools aufruft (Web-Search, Code-Execution, Datei-Lesen, API-Call o. ä.). Ein reiner LLM-Direktaufruf ohne Tool-Use zählt nicht.  
> **Nachweis:** Log oder Screenshot, der mindestens einen Tool-Call zeigt.

## Tools pro Agent

### Manager – echtes Tool-Use (P1-Kern)

Der Manager wählt im ReAct-Loop (`rag_react_node`, max. 3 Runden) per Function Calling situativ aus **6 Tools**. Das ist **kein** reiner LLM-Direktaufruf.

| Tool | Typ | Was es macht | Definition / Ausführung |
|------|-----|--------------|-------------------------|
| **`memory_search`** | LLM → MCP/RAG | Interne Brand-/PDF-Fakten suchen | `manager_tools.py` → `RAGService.search()` |
| **`memory_list`** | LLM → MCP/RAG | Überblick Memory | `memory_list` Dispatch |
| **`memory_store`** | LLM → MCP/RAG | Dauerhafte Notiz speichern (nur auf Wunsch) | `memory_store` Dispatch |
| **`web_search`** | LLM → DuckDuckGo | Aktuelle Web-Infos | `web_search_service.py` |
| **`get_post_data`** | LLM → posts.json | Steckbrief/Preview lesen | `get_post_data` |
| **`check_post_data_completeness`** | LLM → Steckbrief-Gate | Pflichtfelder prüfen (sichtbare Agent-Entscheidung) | Observation `missing=[…]` / `complete` |

Schemas + Dispatch: `backend/app/graphs/support/manager_tools.py`. Loop: `rag_react_node` in `rag.py`. Forced `memory_search` nur HF-Fallback.

**Tests:** `test_agentic_rag.py`, `test_multi_tool_react.py`, `test_manager_tools.py`

### TextAgent – externe Modell-APIs

| „Tool“ / API | Typ | Datei |
|--------------|-----|-------|
| HuggingFace Text-Generate | API-Call (Inference) | `text_agent.py` → `self.hf.generate(...)`; geloggt u. a. als `huggingface_generate_text` |

Kein eigenes Function-Calling-Tool-Schema; nutzt RAG-Kontext, den der Manager vorher per Tool geholt hat.

### ImageAgent – externe Modell-APIs (+ multimodale Eingabe)

| „Tool“ / API | Typ | Datei |
|--------------|-----|-------|
| HuggingFace Text-Generate (Prompt) | API-Call | `image_agent.py` → `generate_prompt` / `hf.generate` |
| HuggingFace Text-to-Image | API-Call | `image_agent.py` → `hf.generate_image` (o. ä.) |
| HuggingFace Image-to-Image | API-Call | `image_agent.py` → `hf.generate_image_from_image(...)` bei `source_image` |

### Log-Ausschnitt (Tool-Call, forced)

```
[TAO 03] agent=classify_intent_node  status=success
  Thought:     Detected a question about stored RAG/memory content.
  Action:      classify_intent
  Observation: Memory inquiry selected. Answer from memory_search / memory_list.

[TAO 04] agent=create_plan_node  status=success
  Thought:     Created high-level execution plan.
  Action:      create_plan
  Observation: {'required_agents': [], 'needs_rag_check': True, 'expected_artifacts': ['memory_answer'], …}

[TAO 05] agent=rag_react_node  status=success
  Thought:     Forced memory retrieval for query 'aliens'.
  Action:      call_memory_search
  Observation: Retrieved 1 on-topic memory item(s). Summary: Aliens haben blaue Haut und fahren immer in roten Autos
```

**Kernzeile:** `Action: call_memory_search` → Tool-Aufruf auf die Memory-/RAG-API mit Observation (Treffer).

### Log-Ausschnitt (Tool-Call, LLM / nicht forced)

```
[TAO 05] agent=rag_react_node  status=success
  Thought:     Planning retrieval round 1.
  Action:      call_memory_search
  Observation: Retrieved 1 on-topic memory item(s). Summary: Deutschland hat 2014 die WM ('Weltmeisterschaft') im Fußball gewonnen

[TAO 06] agent=rag_react_node  status=skipped
  Thought:     Basierend auf dem gefundenen Eintrag könnte der Text so lauten: …
  Action:      skip_memory_search
  Observation: No tool_calls; RAG skipped.
```

**Kernzeile:** Thought `Planning retrieval round 1.` (kein Forced) + `Action: call_memory_search`.
